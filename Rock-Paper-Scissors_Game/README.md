# Rock-Paper-Scissors Game

A modern, interactive version of the classic playground game, built with React and featuring a dynamic game engine.

## Features

- **Interactive Gameplay**: Smooth user interaction with clear feedback.
- **Real-time Scoring**: Track your wins and losses against the computer.
- **Dynamic Assets**: Uses custom icons and animations for an engaging experience.
- **Responsive Layout**: Designed to look great on desktop and mobile.

## Tech Stack

- **Core**: React, Vite
- **Logic**: Custom state-driven game engine
- **Styling**: CSS Grid and Keyframe Animations
