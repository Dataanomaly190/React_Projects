# Password Strength Validator

A real-time security tool designed to analyze and validate password complexity using advanced pattern matching.

## Features

- **Real-time Analysis**: Immediate feedback on password strength as you type.
- **Complexity Checks**: Validates lowercase, uppercase, numbers, and special characters.
- **Security Score**: Visual indicators for Weak, Medium, and Strong passwords.
- **Clean UI**: Minimalist and focused interface for better user attention.

## Tech Stack

- **Framework**: React + Vite
- **Logic**: Regular Expressions (Regex) for pattern matching
- **Styling**: CSS Transition effects
