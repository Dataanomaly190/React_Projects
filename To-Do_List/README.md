# To-Do List Application

A minimalist, high-performance task management application built with a focus on simplicity and productivity.

## Features

- **Task Management**: Easily add, complete, and delete tasks.
- **Interactive UI**: Smooth state transitions and modern button designs.
- **Clean Layout**: Spacious design to reduce cognitive load.
- **Optimized Performance**: Built with Vite for ultra-fast HMR and build times.

## Tech Stack

- **Core**: React, Vite
- **State Management**: React Hooks (useState, useEffect)
- **Styling**: Modern CSS3
