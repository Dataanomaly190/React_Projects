## General Setup Instructions

To explore any of these projects:

1. **Navigate to the project directory**:

   ```powershell
   cd <Project_Name>
   ```

2. **Install dependencies**:

   ```powershell
   npm install
   ```

3. **Run the development server**:

   ```powershell
   npm run dev
   ```

## Architecture Note

Each project is designed to be standalone. Projects like **Invoice Generator** and **ChatGPT Clone** include backend services located in their respective `/Server` directories. Ensure both frontend and backend are running for full functionality.
